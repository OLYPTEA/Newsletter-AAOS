# UX & Simplification : Rendre l'IA Invisible

## Principes d'Interface
- **Zéro Prompt** : Remplacer les zones de texte libres par des choix suggérés, des boutons de style et des curseurs (ex: "Tonalité : [Sérieux <---> Drôle]").
- **Guidage Pas-à-Pas** : Utiliser un système de "Wizard" (étape 1, étape 2, étape 3) plutôt qu'un tableau de bord complexe.
- **Validation Visuelle** : Afficher les changements de l'IA côte à côte pour permettre une modification rapide.

## Idées pour l'Intuitivité
- **Templates de "Personnalité"** : Proposer des profils d'agents pré-configurés (ex: "L'expert technique", "Le storytelling émotionnel").
- **Interactions Naturelles** : Permettre de modifier un paragraphe en disant simplement "Rends ça plus court" via un bouton, sans réécrire tout le prompt.
