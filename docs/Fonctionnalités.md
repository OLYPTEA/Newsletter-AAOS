# Fonctionnalités & Agents

## Les Agents Proposés
1. **L'Agent Veille (Le Curateur)** : Scanne le web, les réseaux sociaux et les flux RSS pour trouver les meilleures pépites sur un sujet précis.
2. **L'Agent Rédacteur (Le Plume)** : Transforme les sources brutes en un article engageant, avec un ton spécifique (humour, sérieux, provocateur).
3. **L'Agent Optimiseur (Le Stratège)** : Analyse l'objet du mail pour maximiser le taux d'ouverture et suggère des améliorations de structure.
4. **L'Agent Correcteur (L'Œil de Lynx)** : Vérifie la grammaire, le style et la cohérence des liens.

## Flux de Travail (Workflow)
- **Étape 1** : L'utilisateur définit son sujet.
- **Étape 2** : Le Curateur propose une sélection de news.
- **Étape 3** : L'utilisateur valide/rejette les news d'un clic.
- **Étape 4** : Le Plume rédige la newsletter.
- **Étape 5** : L'Optimiseur et le Correcteur finalisent.
